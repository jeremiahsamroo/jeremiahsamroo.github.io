CYK chart parser for context-free grammars

Princeton NLP coursework · Python · 2026

This project implements a CKY/CYK chart parser for a context-free grammar from scratch in Python. The grammar is a ~35-production toy English fragment (S, NP, VP, PP, NBar, Det, Adj, N, V, Prep, COMP, CONJ). The parser first converts the grammar to Chomsky Normal Form, binarizing long rules with intermediate X-symbols, then fills the chart bottom-up — terminals on the diagonal with unary closure, binary rule combinations for longer spans — storing backpointers in every cell so full parse trees can be recovered. When no full parse exists, it recovers the longest well-formed span instead of failing silently.

On the 10-sentence test set it fully parses 7 sentences. For the other 3, the partial-parse recovery is the honest result: for the unparseable “LIGHT GREEN CARS FLY”, for example, it returns the longest well-formed span, the noun phrase “green cars”.

The second half of the project is diagnosing and repairing the grammar itself. The original grammar over-generated: it accepted “The car fly” (a subject–verb agreement violation), “The truck hit the baby the car” (a transitive verb given two objects), and “The man put the baby” (a ditransitive verb missing its prepositional-phrase argument). The fix subcategorizes verbs by valency — intransitive, transitive, ditransitive, trivalent — and rewrites the verb-phrase rules accordingly, with plural noun and verb-phrase rules added, so the revised grammar correctly rejects all three ungrammatical sentences. One honest caveat: the agreement fix is partial. Full singular/plural labeling of every noun and verb rule was not implemented; the plural rules suffice for the test set at hand.
